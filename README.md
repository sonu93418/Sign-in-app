## Versions

- Expo SDK: 55
- React Native: 0.83.6
- React: 19.2.0
- TypeScript: 5.9.2

## Features

- Email input with icon
- Password input with show/hide toggle
- Primary Sign In button with shadow
- Social login buttons (Facebook, Google, Instagram)
- Responsive mobile layout

## Quick Start

```bash
npm install --legacy-peer-deps
npm start
```

If you want an animated GIF preview added to `assets/images/`, say "add GIF" and I'll create and attach it.
